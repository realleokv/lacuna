# Demonstração em três minutos

Antes de gravar, abra o projeto e use um perfil de navegador reservado à demonstração. Os registros serão criados por você; não são resultados de estudantes. Tenha a aula de operações e o painel em abas auxiliares se precisar respeitar o tempo.

| Tempo | Tela/ação | Fala sugerida |
| --- | --- | --- |
| 0:00–0:20 | Início | “Às vezes, o problema da equação está numa base anterior. O Lacuna ajuda a encontrar esse ponto de partida.” |
| 0:20–0:40 | Meu Lumi: escolha cor, acessório e tom; salve | “Este é o Lumi. Ele acompanha a experiência e mantém a cor que o estudante escolheu. O jeito de falar muda; a matemática continua a mesma.” |

| 1:20–1:45 | Complete as demais questões; abra a aula indicada | “Uma aula curta organiza a ideia em passos. As pistas só aparecem quando o aluno pede.” |

## Respostas para preparar a gravação

Após os três primeiros itens do caminho de investigação, a sequência padrão é: `−3+5=2`, `1/2+1/4=3/4`, `18+7=25`, `2x−4=10 → 7`, `−4×3=−12`, `2/6 → 1/3`, `6×4=24`.

A gravação pode usar cortes entre respostas repetitivas, deixando claro que é uma demonstração. Não apresente os números desse teste como desempenho de usuários reais. Não use dados pessoais no apelido do Lumi.

## Lista curta antes da apresentação

- Servidor iniciado e `/api/health` respondendo.
- Mesmo navegador e endereço durante toda a demonstração.
- Fonte e mascote carregados; sem dependência de CDN.
- Cor escolhida preservada após recarregar.
- Caminho da equação para subtração/divisão conferido.
- Denominadores visíveis nas métricas.
- Explicar que exportação JSON não inclui restauração automática nesta versão.
- Se mostrar um link público, testar o deploy real antes; não apresentar o endereço local como publicação.
